# Cyclistic-bike-share-analysis

Cyclistic Bike-Share Analysis: Portfolio Project Overview
This portfolio documentation framework sets up your project using SQL for data processing and Tableau for visualization, adhering strictly to the six-step data analysis process: Ask, Prepare, Process, Analyze, Share, and Act. 
Tech Stack & Project ScopeData Source: Twelve months of historical Cyclistic trip data provided by Motivate International Inc.  Processing & Analysis (SQL): Utilized a database environment to clean, merge monthly tables, and compute variables such as ride_length and day_of_week.  Visualization & Sharing (Tableau): Designed for the marketing director, Lily Moreno, and the detail-oriented executive team.  
Portfolio Documentation Structure
1. Executive Summary & Business Task: Clearly state the goal of maximizing annual memberships by uncovering how casual riders and annual members use bikes differently.
2. Data Preparation & Cleaning: Document data credibility (evaluating against ROCCC), data privacy limitations (lack of PII/credit card tracking), and your SQL cleaning transformations.
3. Analysis & Key Findings: Present SQL summary statistics, including mean ride lengths, max durations, and ride volume distributions across days of the week.
4. Visualizations & Recommendations: Embed interactive Tableau dashboards alongside your top three strategic recommendations for converting casual riders.
